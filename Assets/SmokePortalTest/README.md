# 平地沙尘原型

测试场景为 SmokePortal_Test.unity。SmokePortal_Test 对象绑定 VFX_GroundDust.vfx，DustTest_Ground 为独立平地参照。Source 目录保留官方原图、两张烟雾光照贴图及来源和许可证说明。

图副本保留 HDRP Six Way 烟雾光照、8 × 8 Flipbook、每秒 3 帧的贴图动画和 Octagon 输出。输出使用 Along Velocity，使粒子长轴随实际速度方向展开。移除示例的单次爆发、环形发射、绕中心速度、球形约束及其专用参数计算。

当前参数

1. 持续发射每秒 40 个粒子，容量 384，寿命随机 4 至 7 秒。
2. 局部发射盒中心为 X 负 3、Y 0.25、Z 0 米，尺寸为 1.8 × 0.12 × 4 米。
3. 统一目标风速沿局部 X 正方向，由 Periodic Total Time、Sine、Multiply 和 Add 节点生成。速度为每秒 1.1 米加上振幅 0.2 米的正弦变化，周期 7 秒，范围为每秒 0.9 至 1.3 米。初始化速度和 Update 中的 Relative Force 共用此值，Drag 为 1.5，使存活粒子平滑跟随风速。Turbulence 强度 0.01，频率 0.3，场变换的 Y 缩放为 0.02，仅保留轻微局部扰动。
4. 粒子大小随机 1.4 至 2.2，输出缩放为 0.5 × 1.4 × 1。其中粒子 Y 轴沿速度方向，长宽比为 2.8，长度约 1.96 至 3.08 米。通过更宽、更短的低透明度纹理交叠，减弱上一版的细长条纹。角度和角速度均为 0。
5. 颜色线性 RGB 为 0.52、0.43、0.32。Alpha 在寿命前 30% 从 0 淡入至 0.01，维持至 65% 后淡出至 0。
6. 输出使用 Alpha 混合，关闭 Alpha Clipping，Soft Particle 距离为 0.12 米。相机距离 0.2 至 0.7 米之间淡入。
7. 手动 Bounds 中心为 0.5、0.4、0，尺寸为 16 × 2 × 7 米。

Inspector 调整入口

在 Hierarchy 选中 SmokePortal_Test 场景中的同名对象，展开 Visual Effect 组件的 Properties。若没有 Inspector，使用 Window > General > Inspector 打开。勾选参数旁的覆盖框后调整该对象的数值，退出 Play Mode 后修改并保存测试场景可保留设置。

1. WindSpeed 默认为 1.1，控制基础风速，单位为米每秒。
2. GustAmplitude 默认为 0.2，控制风速起伏幅度，设为 0 可关闭阵风。保持小于 WindSpeed 可避免风速反向。
3. GustPeriod 默认为 7，控制阵风周期，单位为秒，必须大于 0。
4. TurbulenceStrength 默认为 0.01，控制局部扰动强度。

风向仍通过该对象 Transform 的 Rotation Y 调整。以上默认值已序列化在 VFX 图中，公开参数分别连接原有风速、振幅、周期和扰动输入，基础调节已更新这些默认值。已通过导入后连接检查、Visual Effect 组件读值和三个着色器的编译检查，实际调节后的运动观感由编辑器预览确认。

验证范围

上一版斜侧离屏预览中可见更融合的薄尘层，细长条纹减弱，方块仍可见。

本次按顺序完成弱化翻滚、降低透明度和调整风速起伏三项基础调节。Flipbook 从每秒 8 帧降至 3 帧，Alpha 峰值从 0.02 降至 0.01，风参数见上文。保留每秒 40 个粒子与长宽比 2.8。图参数连接和组件读值已核对，初始化、更新和渲染着色器均无编译消息。未进入 Play Mode，未完成新版视觉验收。

下一步由用户在正常玩家高度观察约 15 秒，反馈烟团轮廓、地面可辨认程度和风向。基础形态确认后再处理断续发射节奏，最后判断是否需要减弱烟雾光照明暗。此轮未改动这两项，也未保存场景。尚未做 GPU 性能测量。

当前目标只包含低矮、稀薄、方向明确的风吹尘土，不引入流体求解器、第三方流场项目或障碍物绕行。转动 VFX 对象的 Y 轴可改变整片效果的水平风向及发射区域朝向。

这不是坡地贴合实现。低高度来自平地发射盒、扁平粒子和弱垂直扰动，没有采样 Terrain 高度，也没有障碍物碰撞、SDF 或流体绕流。软粒子仅柔化与不透明表面的交界，不会让粒子绕开障碍物。

测试方块具有 BoxCollider，但此图不读取该碰撞体。方块的深度遮挡和软粒子淡化不是碰撞或贴面滑行。

恢复烟圈时，将测试对象的 Visual Effect 资源重新绑定到 Source/Graphs/VFX_PortalSmoke.vfx 即可。主场景和环境配置未参与本原型修改。
