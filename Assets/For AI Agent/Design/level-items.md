# 关卡物品清单

按**三大关卡**组织，每关列出三类物品（A/B/C）、交互方式、叙事帮助、美术状态。
这是「物品 × 叙事 × 美术」的整合视图，供配置场景和排期美术时统一查阅。

物品分类（详见 [game-design.md](game-design.md)）：
- **A 类**：流程关键道具，F 键拾取，推进游戏进程
- **B 类**：叙事关键物品，相机拍摄触发 Echo，推进情感叙事
- **C 类**：环境关键节点，唯一交互为拍摄，过去/现在对照

美术状态：缺 / 临时 / 完成 / N/A
