# 美术资源列表

追踪游戏所需的美术/音频资源及制作状态。状态分四档：

- **缺** — 还没有，需要制作或采购
- **临时** — 用占位/免费资源顶着，待替换
- **完成** — 最终资源已就位
- **N/A** — 用代码生成或不需要美术
