# 厂区边界基础资源

## 当前场景使用的长墙

使用 `Prefabs/FactoryWall_9m_01.prefab` 至 `FactoryWall_9m_06.prefab`。六版几何与材质一致，仅逐砖颜色分布不同，均无白灰残留。不要直接拖入未配置共享材质的 9 米 GLB。

标准柱心间距 9 米，墙身长 8.25 米、高约 3.68 米、厚 0.50 米，两端定位点分别为本地 X 为 0 和 9。转角和入口按实际距离缩短收口；坡地砖体高度保持不变，下方用混凝土基座接地。

当前主场景有 88 段长墙、89 根柱，固定随机混排且相邻版本不同。旧 3 米模块保留为历史资源，以下尺寸与拼接说明针对旧模块。

## 使用资源

从 Prefabs 文件夹拖入地图，缩放保持 1。三个 Prefab 共享现有大门 GLB 内的材质，移动目录时须保留 Unity 资源引用。

1. FactoryGate 包含两根门柱、双扇门、锁链挂锁，以及门卫室一侧的短墙。外侧突出短墙已删除。原点位于门洞底部中央。
2. FactoryPillar 是独立四面砖柱，约 4.37 米高，原点位于柱底中心。移除了门柱铰链配件，可用于直线或直角连接。
3. FactoryWall_3m 是双面围墙，墙高约 3.68 米，墙体厚 0.50 米。3 米表示相邻柱子的中心间距，实际墙身长 2.25 米。墙段本身不含柱子。

## 直线拼接

1. 第一根柱子的 Position 设置为 0、0、0，Rotation 为零。
2. 第一段墙的 Position 同样设置为 0、0、0，Rotation 为零。
3. 第二根柱子的 Position 设置为 3、0、0。
4. 下一段墙从 3、0、0 开始，第三根柱子放在 6、0、0，以此类推。

围墙的 Snap_Start 和 Snap_End 分别标记两端柱子的中心。定位点是摆放参照，不含自动吸附功能。墙端稍伸入柱体，避免接缝漏光。

## 接大门与转角

大门未接门卫室的一侧使用 Snap_OuterPillar，位于大门本地 X 负 3.17 米。

将墙的 Snap_Start 与该点重合，墙相对大门绕 Y 轴旋转 180 度。下一根柱子位于大门本地 X 负 6.17 米。大门自身已有门柱，此处不需要叠放独立柱子。

转角处共用一根柱子，将新墙绕该柱底中心旋转 90 度，再把下一根柱子放到新墙的 Snap_End。所有模块采用相同地面标高，适合平地拼接。

## 材质与碰撞

沿用暖土黄、浅赭、褪色砖红及少量橙红砖的固定色差，保留墙脚污染、混凝土压顶和白灰残留。复制模块目前会重复相同的污渍和颜色分布，实例随机系统尚未制作。

大门、柱子和围墙分别具有 5、3、2 个 Box Collider。门扇碰撞体随对应门扇移动，资源未附加开门或攀爬逻辑。当前围墙是完整墙段，关卡可翻越位置需要后续单独安排。

## 制作与验证

Blender 源文件和实际拼接预览位于项目根目录 ArtSource/FactoryBoundary。大门源文件仍位于 ArtSource/FactoryGate。为保留现有引用，大门模型保留在同级 FactoryGate_Rebuilt 目录。

Unity 编辑器导入已验证三个 Prefab 的三角面数、材质引用、UV、法线、切线、砖网格顶点颜色与定位点，无缺失脚本。已查看 Blender 的直线与转角拼接预览。Play Mode 通行与碰撞表现待游戏内验收。
