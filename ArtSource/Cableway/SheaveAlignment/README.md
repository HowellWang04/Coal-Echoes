# 塔架滑轮方向修正

2026年10月4日修复标准塔与进站支架的顶部轮组方向。

原模型把轮轴设置为沿 Blender Y 轴，同时将两个轮心沿横梁 X 轴并排摆放，而绳索方向也是 Y 轴。两种塔架均存在相同的90度方向错误。

围绕每侧轮组中心，将完整轮组绕竖直轴旋转90度。轮轴改为沿 X 轴，两个轮心沿 Y 轴前后排列。每个模型调整38个独立构件，包括轮盘、轮毂、摇臂、轴承块、支板与安装螺栓，在已烘焙导出网格中对应1024个顶点。塔身其余顶点位移为零，UV哈希保持一致。

已同步更新 `Tajia02_Metric15` 中两份 Blender 源文件、导出 FBX、Unity 使用的两份 FBX，以及 `Scripts/build_tower.py`。原文件保存在本目录 `Before` 中。模型GUID保持不变，现有10座塔架自动使用修正后的网格，无需旋转整个塔架。

`before.json` 与 `after.json` 记录实际轮盘几何的主轴测量。修复前轮轴与绳索方向点积绝对值为1，修复后小于0.000001。`unity_verification.json` 记录重新导入后的模型验证，轮盘顶点与修正源数据的最大位置差约0.00000036米，场景10座塔架均未出现网格或材质引用丢失。`fix_report.json` 记录修改范围与UV检查结果。

本次修正轮组的平面方向，未改动场景塔架变换、绳索线路、轮组俯仰或运行逻辑。Scene近景已检查，未运行Play Mode。
