# 双页报纸主菜单美术基准

## 已确认的方向

主要参考为本目录 `References/evening-newspaper-reference.jpg`。主菜单是一张摊开的双页报纸，覆盖整个画面，中央有折缝。按 16 比 9 重新排版，文字和照片保持原比例。

MainMenuCamera 照片已调得更接近黑白，保留纸张与油墨质感。双页布局、实时照片与放大转场已接入主场景，当前截图为 `Spread/Runtime/menu-1920.png`，实现说明见 `Spread/Runtime/CLAUDE.md`。

## 参考图观察

参考图为用户提供的《羊城晚报》纸面照片，底部木质展示边不作为菜单美术元素。

| 部分 | 可见细节 | 用于本项目的方向 |
| --- | --- | --- |
| 报头 | 左上朱红色书法大字，笔画粗细和外轮廓有明显变化，红色覆盖并不完全均匀 | 保留少量朱红作为报头与重要交互的强调色，具体中文报头字形待排版预览选择 |
| 英文与日期 | 报头下有一行黑色衬线字；右侧窄长日期框，边框较粗，内部信息分多层 | 英文沿用 Bitter；日期与刊号集中成小框，实际游戏日期、期号仍未定 |
| 大标题 | 主标题有较大字距，横跨多栏，上方有反白栏目条，下面接副标题和密集正文 | 保留标题、引题、副题、正文的明确层级，菜单选项采用容易辨认的大字 |
| 正文 | 以很窄的密集文字栏为基础，文章长短不同，局部跨栏，粗细和字号有变化 | 中文正文按多栏组织，让文章大小交错；标题和菜单可读性优先 |
| 横竖组合 | 横排文章中穿插竖排小标题、边栏和较细的小字 | 用于短通知、栏目标识和侧栏，形成参考图中的阅读节奏 |
| 分隔 | 细直线、局部竖线、波浪边、少量黑底反白条并存，很多文章只以窄留白区分 | 分隔方式随栏目变化，避免每篇文章都套上同一种粗边框 |
| 照片 | 照片嵌入文章栏中，大小与比例不同；灰阶被压缩，深处仍有墨色层次，纸纹穿进亮部 | 厂区主照片采用实时相机画面，保持 16 比 9，置于一个完整页面内，便于放大转场 |
| 油墨 | 大标题和正文接近黑色，照片为灰黑连续层次，细碎颗粒和缺墨打断边缘 | 比上一版减少黄绿染色，墨色更深，细网点仅作为底层纹理 |
| 纸色 | 整体偏暖，局部明暗和色斑不均，边缘、折痕附近有不同程度的污损 | 游戏版本改为较浅的暖灰纸底，旧化有疏密变化，朱红报头保留少量色彩 |
| 折痕与破损 | 页面中部的横折痕明显，上缘有局部破口，纸面褶皱和污点分布不均 | 双页增加中央竖折缝，横折痕贯穿纸面；边缘磨损适量，避免遮住按钮和关键文字 |

参考文章和报刊名称只用于观察版式，不作为游戏文案。正文继续使用具体的洗煤厂消息与生活通知，不加入政治暗示。

## 双页比例与布局

原图为 1206 × 1586 像素。排除底部约 101 像素的木边后，可见纸面宽高比约为 0.81，受照片透视和裁边影响，只作构图估计。两页直接并排约为 1.62，16 比 9 画面约为 1.78。

按目标画幅重新排版。参考画布为 1920 × 1080，中线在横向 960 附近，左右各保留一页的竖向组织。通过调整栏数、文章占栏宽度和留白适配画幅，文字字形与相机照片均不作非等比拉伸，也不靠裁掉报头和页脚来铺满屏幕。

版面采用朱红 Ma Shan Zheng 书法报头、Bitter 英文按钮和思源宋体正文。

左页以报头、日期框、主标题和菜单选项建立第一阅读顺序。Start Game、Continue、Quit 集中成一组，字号大于正文，仍采用英文真实文字与按钮交互。菜单视觉与报纸栏目相容，悬停反馈可使用朱红或细下划线。

右页以较大的洗煤厂照片作为进入游戏的视觉入口，照片下方和周围分配厂区消息与生活栏目。主照片不跨中央折缝，始终保持 MainMenuCamera 的完整构图，其宽高比与最终全屏画面一致。两页文章结构互相呼应，但不复制相同内容。

中文正文、标题和英文菜单继续使用 TextMeshPro。纸纤维、污渍、破损和折痕由独立美术层表现。双页预览已将照片的纸纹与整页坐标对齐，横折痕接续穿过照片；运行时接入时沿用这一坐标映射。

## 进入游戏的流程

等待时看到完整双页报纸。点击 Start Game 后，视图向报纸中的厂区照片放大，直到照片充满画面，再逐渐消退纸墨处理并恢复实时相机原色与细节，之后衔接原有看天空、开场对白和玩家操作交接。此前的报纸飞走动作不再采用。
