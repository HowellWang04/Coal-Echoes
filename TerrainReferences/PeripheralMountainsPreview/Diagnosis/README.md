# 三处不自然过渡的诊断

用户指出南侧整片陡壁、东侧矩形黑印、北侧直接变成峭壁。当前 Scene View 已复现，截图为 `reported_view.png`，射线定位和材质读数在 `probes.json`，修改前后同坐标的高程与坡度对比在 `transition_measurements.json`。

## 实测结论

南侧圈 1 的一处采样从约 34.3 度变为 59.2 度，另一处从约 44.2 度变为 65.3 度。后一处地面降低约 72.6 米，说明既有山坡被新片段与过渡权重拉成了更陡的坡面。

圈 2 初次采样位置实际位于旁边的新坡面，该点从约 7.3 度变为 44.0 度、抬高约 134.7 米的读数不能解释用户所说的平缓地面矩形黑印。用户质疑后重新核对，确认矩形对应旧厂区平台留下的材质权重，当前高度已恢复、旧材质却未同步更新，且本次外围改造前的备份已经包含此印迹。圈 2 已进行仅材质的局部修复，完整证据见 `Circle2/README.md`。

北侧圈 3 的一处从约 4.8 度变为 55.2 度，抬高约 702.2 米。此前使用固定宽度遮罩、几何边界和高度偏移，没有先使拼接两侧的大山势及坡向匹配，造成整片过渡坡和规则轮廓。

现有 Main 接缝约 3 厘米的数值检查只说明块边缘接合误差小，不代表大尺度山形、沟谷和材质分布自然。上一轮将其作为视觉验收依据不足。

## 可重复检查

运行本目录 `check_transition.py` 会读取已保存的修改前后原生高度，不修改 Unity。此次结果为 FAIL，发现 4 个采样点同时满足坡度超过 40 度、比原来增加超过 15 度、深色岩石权重超过 0.9。这是陡面采样指标，不能作为圈 2 矩形印迹的复现或修复验收，也不是限制所有天然岩壁的通用地貌规则。视觉比较仍需固定相同观察位置。

## 修复方向

先只在圈 1 制作修复候选，使用修改前的真实地形作为过渡带边界条件，中心保留区、工厂和索道仍固定。重新选择或摆放外围片段，让接合处的山脚高程接近，沿原有沟谷、鞍部和山脚安排接合边界，避免沿规则几何边缘强行消化巨大高差。

分开处理大尺度山势与原始 DEM 细节。先调整外围低频高度，使边界的高程和坡向连续，检查沟谷出口，再有选择地接回与坡向一致的岩脊、冲沟细节。必要的侵蚀或冲沟修形只作用于接合带，不在中心或整张地图运行。不能用无差别模糊把已有肌理一起磨掉。

最终高度确认后，再统一计算坡度与凹凸材质，检查是否仍有沿遮罩轮廓出现的整片深色带。圈 1 通过固定视角的前后对比后，才将方法用于圈 3。圈 2 是独立的旧材质残留问题，不应通过改变高度修复。圈 3 若无法在现有空间自然落坡，应降低、后移或换用更合适的背景片段，不维持原峰高硬接。
