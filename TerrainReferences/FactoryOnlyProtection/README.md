# 厂区单一保护范围与旧边界修复

2026 年 10 月 10 日已应用并保存主场景。当前固定高度源不再采用旧的中心多边形保护范围，仅固定现场 `Ridge factory` 锁覆盖的厂区。此前 `NativeDEMOnly` 中的多边形和处理脚本作为历史基准保留，不应直接重跑覆盖本轮结果。

## 当前范围

厂区圆心的世界坐标为 X 负 2158.54858 米、Z 负 1787.29346 米，半径 335 米。MapMagic 仍只有这一个启用的 Lock，半径与 40 米过渡参数未改。高度打包另留 1 米采样余量，厂区内部实际高度与材质逐值保持原样。

旧多边形内部和原过渡带进入自由求解区域。旧遮罩仅用于限定本轮修改外缘，不再将旧多边形内部设为固定区。源 DEM 片段的摆放、旋转、缩放及外围已完成的固定部分沿用原值，没有引入随机高度节点。

## 处理方式

保留原始 DEM 的细节与片段坡度引导，通过带柔性高度参考的泊松方程重新求解。40 米参考尺度限制不必要的远处山体漂移，不把任何厂区外区域硬性锁住。厂区与修改外缘采用 160 米平滑权重，输出修正量及其一阶变化在固定边界收敛至零，避免只接高度、不接坡度的折痕。

更新现有 `SheepRange_Native_Main.asset` 和 `SheepRange_Native_Draft.asset`，保留资源 GUID、7 个 MapMagic 节点及现有连接。实际写入 46 份 Main 或 Draft 地形的受影响高度，并按遮罩同步坡度材质与边缘缓存。另同步全部 58 份地形的现有缓存，修正检查中发现的未修改地块旧缓存不一致。未调用 MapMagic 全图生成。已刷新 Factory Heat Haze，恢复沙尘与热浪原开关并保存场景。

## 验证

厂区内高度和受保护材质未变，修改范围外高度及材质未变，全部 21193 个物体 Transform 和唯一 Lock 参数未变。

原 Tile 1,负1 折痕诊断剖面的两侧坡度差从约 1.301 米每米降至 0.086 米每米。数值地形对比见 `tile-comparison.png`，实际渲染见 `line-after.png`，原诊断截图保存在 `Library/TileLineAudit/scene.png`。`unity-before.png` 与 `unity-after.png` 为厂区近景，不能作为折痕位置的对比。

58 份地形已回读，22 组 Main 与 Draft 对应采样最大高差为零。93 组同级接缝未比本轮基准恶化；基准原有最大高差约 0.235 米仍保留，不能宣称全图零接缝。高度写入量化误差不超过 0.01681 米。

局部最大抬升约 30.93 米，最大降低约 34.70 米，主要集中在原保护边界。索道根节点下方采样的最大高度变化约 0.265 米，塔架与站房未移动。Play Mode 的基础贴地、通行和 LOD 观感仍需用户确认。

## 复现与恢复

`backup.cs` 保存本轮实时基准。`prepare.py` 生成厂区固定范围、自由区域及连续坡度引导，复用 `../Circle1GradientPreview/bin/terrain-solver.exe` 产生求解初值，`solve.py` 求解带柔性高度参考的方程。`build_atlas.py` 回填 DEM 精细起伏，`preview.py` 与 `verify.py` 检查候选。此处读取原源 DEM 和历史基准数组，不修改其历史文件。

`apply.cs` 在核对当前高度哈希后写入，`paint_batch.cs` 分批同步局部材质，`readback.cs` 与 `verify.py After` 校验实际结果，`sync_caches.cs` 与 `finish.cs` 完成缓存检查、热浪刷新和保存。备份在 `Backup`，浮点回读在 `Before` 和 `After`。重新执行前必须使用新目录重新备份当前场景，不能直接覆盖本轮基准。
