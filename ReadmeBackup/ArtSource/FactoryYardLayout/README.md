# 厂区杂物摆放

把 `工厂建筑群` 下 04 桶罐与容器、05 堆放物与杂物（煤堆除外）、06 搬运与检修设施里散在空地上的杂物，按种类成组靠墙或靠设备摆放。建筑、设备、路障、路灯和标识不动，层级和对象不变，只改位置和朝向。

## 规则

- 叠在一起的东西（托盘上的水泥袋、桶堆上的纸箱）作为一个整体移动，支撑关系不变。
- 已经贴着墙或设备的杂物保持原位，挡在门前或压在路上的除外。道路包括主路两条车道和 `工厂支路` 下的支路。
- 每扇落地门前 4.5 米、左右各 0.8 米不放东西，厂门内侧留空，道路两侧各留 1.2 米。
- 同种杂物在同一侧路边、20 米内的归为一组，一组沿一面墙排开，最长约 16 米，最多两排。
- 托盘、水泥袋、木箱、纸箱优先靠围墙，桶优先靠储罐和管道，气瓶、推车、梯子优先靠厂房墙。
- 每组前方留 3 米通道（大件放不下时放宽到 2 米），桶和气瓶之间不留大缝，托盘和箱子之间留 0.1 到 0.35 米。
- 倒在地上的单个梯子和气瓶扶正。
- 储罐、管道这类设备按整体凸包算占地，支腿之间和两组管道之间不放东西。
- 落地只认地形和水泥地坪，不认墙基、料仓底座的碰撞盒，这些碰撞盒比模型宽，会把杂物托到半空。

## 结果

环形路改成主路加支路（见 [主路改线](../FactoryRoads/MainRoadReroute/README.md)）之后按新路重跑。410 件杂物分成 245 堆，移动 193 堆共 329 件，其中 61 堆原来挡在门前、19 堆压在新路上，全部找到了位置。`verification.json` 里没有超过 3 厘米的网格穿插，没有杂物压在路面上，杂物底部离地最大 0.15 米（几个纸箱在缓坡上一侧略悬）。两台壁挂空调 `SM_AirConditioning10`、`SM_AirConditioning17` 被报为不接触任何碰撞体，网格上与山墙间距为 0，是那段山墙没有碰撞体。

路障、锥桶和水泥隔离墩没有动，它们可能和关卡通行路线有关。

## 文件

- `export.cs` 在编辑器里采集场景，写入 `Survey/`（体积大，不进 git，可重新生成）。
- `plan_layout.py` 规划位置，输出 `plan.json` 和 `apply_plan.json`，需要 numpy、scipy、matplotlib。
- `apply.cs` 先按 `transforms-before.json` 把 04、05、06 三组复位（路灯、路牌等其他对象不动），再按 `apply_plan.json` 摆放、落地、离墙微调，可重复执行，不保存场景。重跑整套流程时先复位，再依次跑 `export.cs`、`plan_layout.py`、`apply.cs`、`verify.cs`。
- `verify.cs` 检查穿插、落地、悬空和压路，写入 `verification.json`。
- `transforms-before.json`、`transforms-after.json` 是调整前后所有杂物的本地变换，按实例 ID 记录，重开 Unity 后实例 ID 会变，复位需要改用路径匹配。
- `Previews/` 是调整前后同机位的截图，拍于道路改线之前。

几个脚本都通过 Unity MCP 的 execute_code 运行，坐标系 u 沿厂区主路，v 垂直主路。
