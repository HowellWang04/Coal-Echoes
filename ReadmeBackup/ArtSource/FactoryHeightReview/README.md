# 厂区高度整理

厂房按占地低处落地，高坡侧允许埋入。调整对象高度，不修改地形。

范围包含厂房、门卫室、大门、工业设备、围栏与散落物。九台分散空调按各自所在建筑处理，包含两套料仓的共同分组按两套完整设备分别处理，没有修改层级。网格使用最高细节层进行检查，建筑占地按约一米间距采样，散落物按底部网格轮廓接触地面。

建筑与基础采用占地低处高度，固定附件跟随建筑。散落物优先保持堆叠支撑关系，地形高于原支撑面时随整组抬至地形。修正一组原先高于屋顶约 1.35 米的通风设备。宿舍交叠范围内的六段落地围栏按地面放置，不跟随楼内支撑面。

大坡差建筑的高坡侧可能遮住门窗和通道。

`Before/Main Game Scene.unity` 为调整前场景备份。`plan.json` 和 `relationships.json` 保存分组及高度差，`Previews/` 保存场景预览。目录内的 C# 和 Node 脚本用于编辑器中的高度调整。
