# 索道移动

主场景管理对象位于 `场景内Object/索道群/索道移动管理`，已绑定全部12个现有吊斗，原有父级保持不变。默认自动启动，速度1米每秒。吊斗保持竖直，随线路改变水平朝向，并在始发站和终点站回转后继续循环。

## Inspector 使用

选中管理对象后可设置 `进入游戏时自动启动` 和 `移动速度 米每秒`。Play Mode 中提供启动和停止按钮。停止保留当前行程，再次启动继续运动。

编辑模式点击 `开始 Scene 预览` 即可直接观看运动，也可拖动进度滑块查看全线位置。停止预览、关闭此 Inspector、保存场景、脚本重新编译或进入 Play Mode 时恢复预览前的位置和旋转。预览可能使场景出现未保存标记，保存时先恢复原位，不会把预览位置当作新的摆放位置；不会强制清除用户其他修改的未保存标记。

## 关卡操作启动

取消 `进入游戏时自动启动`，在具体交互对象的 UnityEvent 中拖入管理对象，选择 `CablewayMovementManager.StartMovement()`。例如现有 ItemUseTrigger 的 onUse 可使用该方法。需要停止时绑定 `StopMovement()`。具体使用哪个关卡操作尚未确定，当前没有随意绑定交互物。

## 路线与实现

线路从 Cable_0.asset 和 Cable_1.asset 每8个顶点的截面中心提取，两条路线反向拼接后去掉相邻重复点。闭合路线共1354点，世界长度约2581.13米。运行时按累计世界距离采样，不按顶点编号计时，保持跨距和坡度变化时的速度一致。

路线数据序列化在管理组件中。后续改变绳索形状需要同步更新路线；本次 setup.cs 是一次性装配脚本，会拒绝重复创建已有管理器，不能直接用于重建线路。没有新增地形修改、滑轮旋转、装卸煤、站内脱索上轨或玩家乘坐机制。

2号塔下原有 CoalBucket (1) 偏离绳索约8.21米，本次对齐最近线路，保留该吊斗。其余吊斗初始位置未改变。移动对象使用非静态配置。
