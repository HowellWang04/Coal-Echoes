# 内心独白的同步规则

给 AI 看。人改的是 [内心独白](../json-inner-monologue.md)，这份写怎么把它变成 JSON。

- 所有关卡共用一份 `Assets/Narrative/inner-monologue.json`，由 `InnerMonologueUIManager` 引用。不直接手改 JSON。
- 用户说“同步独白”时按文档重新生成，结构是 `lines` 列表，每项只有 `id` 和 `text`。
- 列和字段的对应：`id` 写进 `id`，“独白”写进 `text`；“触发时机”和“中文意思”只给人看，不进 JSON。
- `id` 就是设计文档里的独白编号，写成 M 加关卡号、点、本关序号，比如第一关是 M1.1、M1.2……，第二关是 M2.1、M2.2……，每关按出现顺序从 .1 编起，定下后不要改。代码按 `id` 播放（比如 `Level1HintFlowManager`），场景里也有 UnityEvent 直接填 `id`（第一关有 `FactoryGate`、值班记录本和大门铁链三处），改了都要同步。播放过的 `id` 存在 `Progress/Progress.json` 里，改了 `id` 后旧存档里播过的句子会再播一次。
- 两句之间写 `<br>` 换行，避免自动换行把最后一两个词挤到第二行。
- 游戏里的表现：屏幕下方字幕，一次一到两句，逐字打出，玩家点击加速、打完再点才换下一句或收起，不会自动消失，显示期间玩家不能操作；每句只出现一次；先出独白，点完才出对应的任务提示。
- 改完同步 [游戏文本](../game-text.md)。
