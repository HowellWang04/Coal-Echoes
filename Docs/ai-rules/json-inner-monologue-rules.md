# 内心独白的同步规则

给 AI 看。人改的是 [内心独白](../json-inner-monologue.md)，这份写怎么把它变成 JSON。

- 所有关卡共用一份 `Assets/Narrative/inner-monologue.json`，由 `InnerMonologueUIManager` 引用。不直接手改 JSON。
- 用户说“同步独白”时按文档重新生成，结构是 `lines` 列表，每项只有 `id` 和 `text`。
- 列和字段的对应：`id` 写进 `id`，“独白”写进 `text`；“触发时机”和“中文意思”只给人看，不进 JSON。
- `id` 就是设计文档里的独白编号，所有关卡按出现顺序连续编号（M1、M2……），定下后不要改。代码按 `id` 播放（比如 `Level1HintFlowManager`），改了要同步代码。播放过的记录只在内存里，不存档。
- 两句之间写 `<br>` 换行，避免自动换行把最后一两个词挤到第二行。
- 游戏里的表现：屏幕下方字幕，一次一到两句，几秒后自动淡出，不打断操作；每句只出现一次；先出独白，再出对应的任务提示。
