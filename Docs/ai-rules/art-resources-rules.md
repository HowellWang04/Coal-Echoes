# 美术资源列表的写法

给 AI 看。人读的是 [美术资源列表](../art-resources.md)，这份写改它时守什么规矩。

- 读者和设计文档一样：作者本人、作品集的老师、做 video essay 时回看。列表里只放资源和用途，不写给 AI 的说明。
- 按关卡分节，标题写“第N关　关名”，关名和设计文档关卡地图表里的中文关名一致。每关一张表，两列：资源、用途。
- 物品用游戏内英文名，和设计文档“本关物品”表一致，比如 Lock Pick、Bolt Cutter。
- 用途写玩家在哪里看到、拿它做什么、和关卡哪一步有关。几关都用到的资源列在第一次出现的那关，用途里写后面哪关还用到。
- 不写完成状态、文件路径、制作方法和参数。完成状态写进 `Docs/Specs/Levels/` 下对应关卡 Spec 的美术资源核对表，制作记录写进 `ArtSource/` 对应目录的 CLAUDE.md。
- 流程还没定的关写 **待定**，关卡流程确定后再补表。
- 增删资源后同步对应关卡 Spec 的美术资源核对表。设计文档的“美术资源列表”一节只放链接，不抄表。
