# 游戏设计

## 概述

- 类型：第一人称叙事探索
- 背景：中国西北的虚构矿区。爷爷曾在山脚下洗煤厂工作，主人公在工厂关闭后返回，沿山路和废弃运煤索道走向山上的旧装煤站。具体年代随叙事文字统一。
- 视觉参考：石炭井的山地矿区氛围加大武口洗煤厂的工业设施，组合成虚构厂区。夏季，无积雪。
- 基调：苍凉、温情、怀旧。
- 开场动机：爷爷去世后，主人公办完后事，回到爷爷的卧室整理遗物，发现一张尘封多年、已经泛黄的老照片和爷爷日记。照片是爷爷与工友在工人宿舍大门前的合影。主人公带着它们骑摩托车来到洗煤厂，进入厂区后，循着照片寻找当年的宿舍。
- 上山动机：随着探索和日记线索展开，主人公逐渐了解爷爷与一位工友未能完成的山顶夜景约定，产生替他们完成约定的愿望。
- 终点：夜晚抵达上站外的山脊，拍下如今大部分灯光已经熄灭的厂区，把新照片收进自己的手账。宿舍门前的旧合照是故事起点，山顶的新照片是故事终点。

## 操作与交互

按 F 拾取或使用道具，比如拿起断线钳、剪断大门铁链。

用相机拍摄物品和风景，部分物品会触发回响，解锁相关文字。

背包只收流程工具，按物品列表显示缩略图、名称和用途，点击放大查看。回响物品留在现场拍照，日记使用独立页签。断线钳使用后保留在背包。

| 类型 | 例子 | 作用 |
|---|---|---|
| A 流程道具 | 断线钳 | F 拾取或使用，打开通路 |
| B 叙事物品 | 街道照片 | 拍照触发回响 |
| C 环境节点 | 标语墙、窗外山头 | 只能拍，对照过去的繁荣与现在的荒废 |

## 回响系统（Echo）

拍到 B 类物品时：

先决条件为已在摩托车旁按 F 获得爷爷日记。此前整个回响系统关闭，普通拍照仍可用，获得日记后不追溯此前照片；日记解锁和系统门槛尚待实现。

1. 自动判断物体的大小、位置和遮挡，满足条件后白色四角取景框变黄。手持和全屏模式都显示，在各自取景画面顶部以同比例字号提示未发现或已发现的回响，并轻轻落下回弹。黄框时拍照只记录最靠近中心的一个，保存成功后记录发现状态。已替换原物品高光，Play Mode 待验收，具体规则见[回响取景提示 Spec](echo-targeting-spec.md)。
2. 照片带上 Echo 数据，在手账工具栏里有描边；拖进手账后照片旁出现主角的手账文字。
3. 爷爷日记对应位置贴出一张便签，写主角对这条线索的理解。主角从不直接在爷爷的日记上写字。

Player Panel 新增“探索记录”页签，按关卡显示目标与完成情况，小 UI 用已发现数 / 总数表示回响进度。只把已发现条目放入网格，复用相册的四列、每页 16 项和翻页 UI，并关联主角手账记录。主线与收集分别记录，重复拍摄不重复计数；界面尚待实现，细节见[开场与第一关流程 Spec](opening-level-one-spec.md)。

两套字体：爷爷日记用旧式手写体，主角便签用简洁现代的字体，形成“过去的记录”和“现在的回应”的对话。

## 开场与提示界面

主菜单镜头看向工厂，点击开始后菜单淡出，镜头抬向天空，居中逐字显示英文背景文字。生成中左键点击文本框加速本段，完整显示后出现向下箭头，再点击进入下一段。新游戏不能直接跳过开场，继续游戏不重播。最后文字淡出，镜头向下衔接玩家第一人称视角，再开放操作。

玩家已经下车，站在摩托车旁。对准摩托车按 F 即获得爷爷日记，不制作日记实体模型或必需的行李模型，摩托车保持原位。获取后 Player Panel 才出现爷爷日记页签，所有页面可翻阅，同时开启回响系统。旧存档默认已获得日记。游戏内语言统一英文。

右上角显示当前目标及获得物品等临时通知，采用小图标、短细线和简短文字，通知结束后恢复目标。F 交互提示靠近物品，回响识别文字保留在取景画面顶部。详细行为和待定项见[开场与第一关流程 Spec](opening-level-one-spec.md)。

## 关卡

### 第一关 厂区入口

1. 开场演出结束，玩家在摩托车旁，按 F 拿取爷爷日记。
2. 查看厂区大门，发现铁链上锁。
3. 探索门卫室，拾取断线钳（Bolt Cutter，A 类道具）。室内保留街道照片和值班记录本两个 B 类回响物品。门卫室在大门上锁时必须可从厂外到达。
4. 回到大门，在铁链处按 F 使用断线钳，铁链与挂锁消失，两扇门打开，断线钳保留在背包。玩家自行走入，不传送。
5. 穿过入口进入厂区，第一关主线完成；根据随身旧合照中工人宿舍大门的线索寻找宿舍，衔接第二关。

街道照片和值班记录本均不作为开门或本关完成的强制条件，第一关收集总数为 2，C 类暂不做。街道照片与开场获得的工友合照是两张不同的照片。日记只作为回响系统的前置，不额外限制移动和开门。

大门：红砖门柱、混凝土压顶、双扇钢板门，褪色灰蓝漆、边缘和下沿锈蚀，中央铁链挂锁。

已核对模型包含独立门扇、转轴和锁链挂锁，可沿用现有模型接入开门及铁链隐藏。断线钳使用和开门流程尚待实现，具体资源配置见[第一关美术配置](art-assets.md)。

### 第二关 宿舍与上山路线

先探索旧合照中的工人宿舍，通过班组生活和日记线索了解爷爷与工友的往事。旧合照在开场整理遗物时已经获得，用于引导玩家来到宿舍。宿舍内的具体物品、交互和文字待设计。

后续前往索道下站，从洗煤厂沿废弃运煤索道走向上站。宿舍到下站的衔接、上山的具体通行方式、交互和物品待设计。沿途逐步呈现爷爷与工友的约定、排班和一次次推迟，让玩家的上山动机从了解过去转向替他们完成心愿。

运输关系为附近山腰旧矿口经短轨道或溜槽向上站供煤，吊斗在上站装煤后下行至洗煤厂，空斗返回上站。短轨道与溜槽的具体选型待场景设计确定。玩家探索方向与当年煤炭下山的方向相反。

### 第三关 山顶

山顶区域由旧装煤站、值班室和站外山脊组成，规模控制在几个相连的小空间。

1. 装煤作业区利用已有站棚和回转设备，补足煤仓或装料口，并以短轨道或溜槽指向附近封闭的旧矿口，使索道用途清晰。
2. 值班室承接交接、通信和工人生活，可用交接记录、旧电话、搪瓷杯和维修工具表达，具体物品待选定。
3. 一小段检修路从上站通向能俯瞰厂区的山脊。最后的开阔视野与前面的工业空间形成节奏变化。

结尾发生在夜晚。玩家看见已经停产的厂区，拍下此刻的真实景象，将照片放进自己的手账，回应爷爷与工友未能实现的约定。两人的共同愿望与当年的灯火通过此前收集的线索呈现。结尾文字、夜景照明及拍照入册的交互细节待设计。
