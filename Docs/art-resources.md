## 第二关　宿舍楼

| 资源 | 用途 |
| --- | --- |
| 宿舍楼前的旧旗杆 | 宿舍楼正门前空地上一根不挂旗的老旗杆，油漆剥落生锈，升旗绳一边断了吊在半空，基座开裂、积着沙；玩家进大门后转向宿舍时它立在门前，把视线引向宿舍楼，只做环境叙事 |
| 207 室 | 外公和工友住过的寝室，进入宿舍的过场文字后玩家站在这里；四张床、一张桌子、一个炉子，窗外能看见爬上山的索道；拍下山路图后在门口离开房间 |
| 桌子抽屉 | 207 室桌子上一直半开着的抽屉，山路图就在里面，不能开合 |
| 山路图 | 工友画在旧工票背面的上山路线：从宿舍 207 沿主路走到底，转进小路到索道下站，扒上回山的吊斗，数着塔架到上站，再走上站背后的栈道到山脊，山脊上的观景平台画着叉；正面是印好并填过的旧工票。收在桌子抽屉里，按 E 查看正反两面，拍下来推进第二关 |

## 第四关　索道终点站

| 资源 | 用途 |
| --- | --- |
| 上站背后的木栈道 | 站房背后伸出的旧木栈道，先平着架空跨过站后的低洼，再分三段木台阶顺山脊往上，中间有歇脚平台；玩家沿它从上站走到山头 |
| 山头观景平台 | 栈道尽头、山路图上画叉那道山脊上的木平台，四面有栏杆；玩家在这里读日记最后一页，把山下的厂区和星空拍进同一张照片 |
| 上站下的矿洞口 | 站房东北角下面山体里封死的矿洞口：水泥端墙和翼墙，拱门钉着旧木板、中间一道锈铁栅门，铁轨从门下伸出来，穿过洞口前的平台到矸石堆边的车挡，轨道上停着一辆空矿车。玩家走不下去，从栈道和山头往下看得见，不用文字就交代了索道运的煤从山上的矿里来 |
