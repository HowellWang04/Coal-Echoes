# Coal Echoes 剧本

一款第一人称探索游戏。主人公带着外公的旧日记和一张工友合照，回到外公工作过的废弃洗煤厂，用相机拍下过去和现在的对照，收进手账。全部游戏文字见[游戏文本](game-text.md)，关卡规则见[设计文档](design.md)。

## 一句话故事

外公和工友约好爬上山脊，看厂区夜里的灯火，一拖再拖，直到 1988 年工厂关停也没去成。几十年后主人公替他们走完这条路，山下的灯早已熄灭，眼前只有月光和星空。

旧合照是故事的起点，山脊上拍下的星空照片是终点。情绪从好奇、怀念，到遗憾，最后落在释然。

## 内核

洗煤厂早就人去楼空。大时代里，一座厂建起来、红火过、又停下，这是几十年的事；可落在外公和工友身上，只是一张合照、一本日记、一张背面画着铅笔路线的工票，和一句说了好多年的“下回”。人走了，这些小人物的痕迹却还留在原地：207 的床和炉子还摆着，抽屉里的图还在，吊斗还挂在缆绳上，山脊上的栈道还通着。

几十年里，自然慢慢把这里收了回去。沙丘埋了主路，枯草长进了厂门，索道停在半山，灯一盏盏灭了，换成月光、星空和风。可厂子没有就此被抹掉，它和山、沙、夜空长在了一起，安安静静的，身上还带着当年人留下的印子。

## 故事走向

| 场次 | 发生了什么 | 作用 |
| --- | --- | --- |
| 序幕 | 一份 1980 年的厂报，报上的厂区照片褪成真实画面，几十年在几秒里过去。独白交代外公去世，主人公带着遗物骑车回到厂门口 | 先看厂子活着的样子，再看它废弃 |
| 第一关　工厂大门 | 读日记第一页：外公进厂，十二个新职工在门口拍了合照，他分到 207 室，听老师傅说从山脊上能看见全厂的灯。主人公照合照的角度重拍大门，剪断铁链进厂 | 同一扇门，当年站满了人，现在只剩锁；埋下上山看灯的念头 |
| 第二关　外公的宿舍 | 主路被沙丘埋住，主人公走进外公住过的 207 室。抽屉里还放着建国画的上山路线图，说好上山那晚才拿出来 | 两人的约定第一次摆在眼前，主人公决定替他们上山 |
| 第三关　索道下站 | 照着路线图走到索道下站，给锈住的电机上油，停了几十年的索道重新转起来。主人公坐进空吊斗上山，路上想起 1983 年山洪冲垮塔基，约定又一次搁下 | 坐上他们当年想扒的吊斗，走他们没走成的路 |
| 第四关　索道上站 | 月夜里走到路线图上画叉的山头。日记最后一页：两人倒班错开，见面只说一句下回；1988 年停产，日记写到这里为止 | 到了约好的地方，确认他们一直没来过 |
| 结尾 | 山下厂区一片漆黑，没有灯火。主人公拉近拍下外公的宿舍楼，再拉远把月光下的厂区和星空拍进同一张照片，和旧合照收在一起，打算明天带回家给妈妈看 | 想看的是灯火，看到的是星空；从遗憾走向释然 |
