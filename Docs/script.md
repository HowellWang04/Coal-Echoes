# Coal Echoes 剧本

一款第一人称探索游戏。主人公带着外公的旧日记和一张工友合照，回到他工作过的废弃洗煤厂，用相机和手账记下过去和现在的对照。全部游戏文字见[游戏文本](game-text.md)，关卡规则见[设计文档](design.md)。

## 故事梗概

外公去世后，主人公在遗物里找到一本旧日记和一张泛黄的工友合照，骑摩托车回到外公工作过的洗煤厂。厂子当年突然关停，外公那一批工人是最后的住户，之后再没人来过。

主人公沿着日记和合照的线索进厂、找到外公住过的宿舍，再顺着废弃的运煤索道上山。一路慢慢知道，外公和一位工友曾约好爬上山顶看厂区夜里的灯火，却一再推迟，直到停产也没去成。

最后主人公在夜里登上山脊。山下的厂区早已人去楼空，他们想看的那片灯火不在了，眼前只有月光下的厂房、索道塔架和满天星星。主人公把这一幕拍进照片，收进手账。旧合照是故事的起点，这张照片是终点。

## 人物与工具

| 项目 | 说明 |
| --- | --- |
| 主人公 | 外公的外孙辈，玩家视角 |
| 外公 | 洗煤厂老工人，只通过日记出场 |
| 工友 | 和外公约好上山看夜景的人，姓名与经历待定 |
| 外公日记 | 过去，外公的原话 |
| 相机 | 现在，拍到留着当年痕迹的物品会触发回响 |
| 手账 | 主人公自己的记录，照片和文字由玩家自由摆放 |

## 游戏走向

| 场次 | 玩家经历 | 作用 |
| --- | --- | --- |
| 序幕　旧报纸 | 一份 1980 年的双页厂报铺满屏幕，全是厂里的日常小事，右页的厂区照片是实时画面印成纸墨的样子，从索道塔架上俯拍厂区，缆绳从画面一角伸下山。玩家点击 Start New Game | 第一眼看到的是厂子还活着的时候 |
| 时间流逝 | 报纸推近那张照片直到铺满屏幕，纸墨褪去变回真实画面。云飞快掠过，宿舍楼由新变旧，厂内主路隆起一道沙丘 | 几秒钟里过去几十年。沙丘留在原地，之后挡住主路 |
| 开场独白 | 镜头抬向天空，五段独白：外公的葬礼、遗物里的合照和日记、小时候听过的往事、骑摩托车回到洗煤厂。镜头落下，玩家站在摩托车旁，面前是锁着铁链的大门，浮现标题 Chapter One　The Factory Gate | 交代来由，玩家接手 |
| 第一关　工厂大门 | 从摩托车储物箱拿到日记、合照和撬锁工具，第一次打开面板，读日记第一页：1980 年 10 月 3 日外公调来洗煤厂，十二个新职工在门口拍了合照，他分到 207 室。站进大门前的光圈，照着合照的角度重拍一张。撬开门卫室，翻看值班记录本，里面记着有个工人下班后从北边山路偷偷上了山。拿到断线钳，剪断铁链，大门打开 | 过去和现在的第一次对照：同一扇门，当年站满了人，现在只剩锁。第一次听说有人想上山 |
| 第二关　外公的宿舍 | 主路被沙丘挡住。用撬锁工具打开宿舍入口，一段过场文字后玩家已站在 207 室，房间保持着外公离开时的样子。在房间里找一样东西（**待定**），从宿舍另一侧出去，绕过沙丘到工厂后方 | 走进外公生活过的地方 |
| 第三关　索道下站 | **构想**　从厂里的索道站出发，沿废弃的运煤索道往山上走，和当年煤运下来的方向相反。途中通过日记和现场物品拼出外公和工友的约定：提出、推迟、再推迟 | 约定成形，遗憾累积 |
| 第四关　索道上站 | **构想**　山上的旧装煤站和值班室，再走一小段检修路到能俯瞰厂区的山脊 | 到达他们约好的位置 |
| 结尾 | **构想**　有月亮的晴夜，主人公站在山脊上。山下的厂区一片漆黑，没有他们期待的灯火。抬头是月光下的厂房、煤堆、沙丘和一座座索道塔架，星星落到山脊尽头，只听得见风。玩家举起相机，把厂区和星空拍进同一张照片，放进手账 | 想看的是人的灯火，看到的是灯灭以后的星空和月光。情绪从遗憾转向释然和静谧 |
