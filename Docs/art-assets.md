# 关卡美术配置

按关卡整理，只列已确认的配置。已有资源不代表最终效果已验收。

## 第一关 厂区入口

主菜单与背景文字 → 摩托车旁拿取日记 → 抵达上锁的大门 → 探索门卫室 → 拿到断线钳 → 剪断铁链 → 从大门进入厂区 → 根据旧合照寻找宿舍。具体行为见[开场与第一关流程 Spec](opening-level-one-spec.md)。

### 待确认

摩托车具体资源，断线钳在门卫室内的具体位置，以及门卫室其他陈设。门卫室锁门时的可达通路需要试玩核对。第一关保留街道照片和值班记录本，C 类暂不做。
