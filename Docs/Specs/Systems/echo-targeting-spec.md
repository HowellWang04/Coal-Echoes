# 回响取景提示 Spec

自动判定、白黄取景框、英文提示和发现记录已接入主场景。下列数值为可调参数。

## 玩家看到的效果

取消回响物品的模型高光，改为取景框变色和文字提示。

新游戏必须先在摩托车旁按 F 获得外公日记，才开启整个回响系统。获取前不识别回响、不显示黄框或回响文字、不写发现状态与回响照片数据，也不弹出首次发现通知。普通白框取景与普通拍照仍可用，之后不会追溯解锁此前照片；需要重新有效拍摄。旧存档默认已经获得日记，具体规则见[开场与第一关流程 Spec](../Levels/opening-level-one-spec.md)。

普通取景时显示白色四角框。对准回响物品，且距离和视角满足条件后，四角框变黄，当前取景画面顶部显示回响提示。物品本身保持原有材质和外观。

只有黄框出现时按下快门，才算拍到对应的回响物品。白框时仍可拍普通照片，但不记录回响。只出现黄框不会解锁回响，照片成功保存后才算发现。

快门只在全屏取景时有效，手持时按快门没有反应。手持的白黄框照常提示，玩家看到黄框后按 V 切到全屏，切换后重新判定，再按快门。

## 已确认的布局

| 模式 | 四角框位置 | 文字位置 |
| --- | --- | --- |
| 手持取景 | 手持相机画面的中央，四角框完整位于相机显示区域内 | 相机显示屏内部的顶部中央，跟随屏幕位置与倾斜 |
| 全屏取景 | 屏幕中央 | 全屏画面顶部中央 |

四角框固定在各自画面的中央，不跟随物品移动。手持和全屏使用相同的白色、黄色状态。

四角框使用简单圆角线条，宽高各占对应取景画面的约 40%，普通状态为白色，符合条件时为暖黄色。手持模式按相机显示区域缩放，全屏模式按屏幕缩放。

检测到回响时，四个角在约 0.18 秒内向外展开，框宽高增加约 6%，保持线宽与角线长度；失去目标时收回。该动效只改变显示，不扩大回响判定范围，切换模式或收起相机时重置。

手持框投影跟随相机显示屏的位置和倾斜，在屏幕 UI 层绘制，避免景深、TAA 和曝光模糊线条。手持线宽首版为参考分辨率下 2.5 像素，全屏为 3 像素。相机构图网格默认关闭，玩家仍可手动勾选。

文字使用现有 Imprima 字体，不加底板。字号为当前取景画面高度的 5%，全屏 1080p 时为 54，手持时按相机显示屏投影高度同比例缩放。文字框顶部留取景画面高度 2.5% 的边距，文字框高为 10%，文字居中，两种模式比例一致。

提示通过现有 DOTween 从上方轻轻落下并回弹，约 0.16 秒淡入、0.42 秒完成下落、0.48 秒收住轻微摆动，字号本身不参与缩放动画。首次显示、换目标或发现状态改变时播放，持续对准同一目标不会反复播放。移开、切换模式或拍摄时立即停止并隐藏提示。

## 状态与切换

| 情况 | 四角框 | 回响文字 | 是否解锁 |
| --- | --- | --- | --- |
| 新游戏尚未获得外公日记 | 普通白框 | 不显示 | 否，只能保存普通照片 |
| 普通取景，未对准符合条件的回响 | 白色 | 不显示 | 否 |
| 白框时拍照，即使画面中包含回响物品 | 拍摄期间隐藏 | 不显示 | 否，只保存普通照片 |
| 对准尚未发现的回响，满足自动判定条件 | 黄色 | Undiscovered Echo | 否 |
| 对准已经发现的回响，满足自动判定条件 | 黄色 | Discovered Echo | 不重复解锁 |
| 对准需要对焦的回响，其他条件都满足但没对上焦 | 白色 | 框下方显示白色 Out of focus | 否，按快门只保存普通照片 |
| 偏离目标或离得太远 | 恢复白色 | 隐藏 | 否 |
| 黄框时按下快门，并成功保存新的回响照片 | 拍摄期间隐藏，返回取景后重新判定 | 再次对准时显示已发现的回响 | 是 |

提示统一使用英文。`Undiscovered Echo` 表示未发现的回响，`Discovered Echo` 表示已发现的回响，`Out of focus` 表示需要对焦的回响已经框好但还糊着。`Out of focus` 和顶部文字同字体，字号为取景画面高度的 3.5%，位于四角框下边缘下方，不播放入场动画。

收起相机、切换取景模式、查看拍摄结果或进入遮住取景画面的面板时，隐藏这套取景提示。返回取景后按当前目标重新计算，不沿用离开前的黄框。

## 判定规则

自动汇总一个回响物品自身模型的网格范围，计算它在当前取景画面中的中心和大小。不逐个绘制识别区域，也不分析画面像素。照片按整个相框判断，允许宽松误差。要拍清楚上面字迹的物品可以单独要求对焦，见下面的对焦一节。

模型范围只包含该回响物品，不把它所在的桌子、房间或建筑一起算入。只使用实际显示的模型，避免重复统计不同 LOD。

统一使用下列规则，大部分物品无需单独配置。特殊物品只有实际出现问题后才调整。

| 项目 | 确定方案 |
| --- | --- |
| 距离 | 默认相机到物体中心不超过 3 米，特殊物品可单独调整最大距离 |
| 对准范围 | 物体中心进入四角取景框中央的一半区域，宽高各为取景框的 50%；设了站位点的回响不看这一条，改为相机朝向和站位点朝向的夹角不超过站位角度 |
| 入镜大小 | 自动计算物体在画面中的大小，不能只是远处的小点；不要求整个模型完整入镜 |
| 遮挡 | 用自动采样检查物体是否被挡住，中心等主要部分被挡住时不变黄，允许边角少量遮挡，不隔墙触发；Ignore Raycast 层的隐形挡墙（比如沙丘的 `Blocker`）不算遮挡 |
| 多个目标 | 只选择符合条件且最接近取景中心的一个，提示文字和本次照片记录都对应它 |
| 边界抖动 | 退出范围略宽于进入范围，轻微手抖不立即变白；明显移开、遮挡或转到照片背面时立即恢复白框 |
| 对焦 | 只对勾了 `requireFocus` 的回响生效，其余条件都满足后再看物体是否落在景深内 |
| 焦距上限 | 只对填了 `maxFocalLength` 的回响生效，取景相机焦距超过它就不变黄，给要用广角拍的场景用，目前只有第四关的山脊夜景 |

入镜大小的统一初始试调值为物体投影包围框的短边至少占取景画面短边的 10%，采用未裁剪的投影范围，不根据模型在世界中的固定尺寸判断。这个数值是自动方案的首版调参起点，实际以门卫室相框预览校准。物件可以在 `EchoTrigger` 上用 `minScreenSizeOverride` 单独改，第二关抽屉里的山路图纸片要读清上面的字，提高到 0.3，玩家得拉长焦距。

### 对焦

`EchoTrigger` 勾了 `requireFocus` 的回响，要拍清楚才算，目前只有第二关的山路图。`EchoTargetDetector` 用取景相机当前的焦距、光圈、相机参数面板的对焦距离和物体中心的深度，按 HDRP 物理相机景深的同一套薄透镜公式算出物体处模糊圈的直径，除以底片高度，不超过 `maxFocusBlur` 才算对上焦。光圈收小景深变大，判定跟着变宽，和画面里看到的清晰范围一致。

其他条件都满足、只差对焦时，这个回响记为 `OutOfFocusTarget`，四角框保持白色，框下方显示 `Out of focus`，按快门只保存普通照片。对焦的退出阈值同样放宽约 10%。`maxFocusBlur` 首版为 0.003，约等于 1080p 下 3 像素；山路图在 1.2 米处时，107mm、f/16 下对焦距离在约 1.07 到 1.37 米之间都算清楚，f/5.6 时缩到约 1.15 到 1.25 米，要在 Play Mode 里再调。

在最大距离内，大物件可在较远处满足入镜大小，小物件需要靠近。3 米是默认上限，自动尺寸判断不会绕过这个上限。

防闪烁的首版退出阈值在进入阈值上放宽约 10%，只作用于距离、中心范围和入镜大小。保持黄框期间按快门仍算有效拍摄，不另外用进入阈值否定结果。

### 照片正反面

能看清照片正面即可，不必完全正对，拍相框背面不触发。这里通过照片朝向和自动入镜大小近似判断，不分析贴图内容或要求阅读照片细节。

包围盒本身分不出哪面印着照片。现有 `OldPhotoFrame` 的[导入脚本](../../../ArtSource/Props/OldPhotoFrame/UnityIntegration/ImportAndPlace.cs)通过玻璃 `GlassPane` 和照片纸面 `Photograph` 的位置确定正面，并把预制体规范为本地正 Z 朝前、本地正 Y 朝上。[放置记录](../../../ArtSource/Props/OldPhotoFrame/UnityIntegration/placement.json)也记录了来源正面方向。

实现时，将该预制体的正面方向转换到世界坐标，判断相机是否位于照片正面一侧。允许斜拍，不要求相机与照片表面垂直；恰好侧对或位于背面时不触发。物体移动或旋转后，正面方向随物体变化。

其他来源的照片模型不能默认正 Z 就是正面，导入时需统一朝向。普通非照片回响不强加照片的正反面要求。

取景提示与拍摄判定必须一致。以按下快门那一刻的黄框状态和对应目标为准，不能因为之前出现过黄框就算成功，也不能额外用一套更严格的条件否定当前黄框。拍摄时隐藏界面不会取消已经记录的结果，拍摄结束后不重新选目标。

## 发现记录和拍照结果

“符合拍摄条件”表示可以记录这个回响；“已发现”表示此前已经成功拍照记录过。两者分开判断。

新回响成功拍摄并保存后，继续保留照片关联的回响文字和手账文字显示。拍照失败或照片未保存时，不标为已发现。

重复拍摄可以生成新照片，并保留对应回响文字，但不重复计入发现。退出后再次进入游戏，已发现状态应能恢复。

每个回响使用固定且唯一的编号保存发现状态，不能使用会变化的物体名称或运行时编号。

旧版照片记录只有文字、没有回响编号时，不根据相同文字猜测归属；保留原照片和回响文字，无法恢复的单个物品发现标记在迁移核对中列出，不清空旧存档。

拍摄后的成功提示与取景文字分开。首次发现且照片保存成功时，右上角盖下一枚 ECHO 印章（和相册、手账里回响照片上的是同一枚），从放大、透明落到原尺寸，略压过头再弹回，随机斜几度；落定后印章右边逐字打出 `New Echo Discovered`，暖白字加煤灰黑柔影，打完停 2 秒，文字先淡出，印章最后淡出。重复拍摄仍可保存照片，但不再次弹出成功提示。

## 实现位置

代码与主场景已完成以下配置。

| 位置 | 职责 | 当前实现 |
| --- | --- | --- |
| `EchoTrigger` | 回响数据及模型范围 | 固定编号、自动模型范围、可选最大距离、入镜大小、照片正面限制、对焦要求和焦距上限 |
| `EchoTargetDetector` | 当前取景目标 | 使用当前取景相机，检测距离、站位、中心、尺寸、遮挡、朝向和对焦，只选一个目标；对焦从 `CameraTweakUIManager.FocusDistance` 读 |
| `EchoTargetingUI`、`EchoViewfinderGraphic` | 取景界面 | 手持显示屏内的框、全屏中央的框、屏幕偏上文字及框下的 `Out of focus`（`EchoFocusText`） |
| `CameraSystemManager` | 拍摄与记录 | 快门时锁定黄框目标，截图前隐藏提示，照片保存成功后写入回响 |
| `EchoDiscoveryStorage` | 发现状态 | 保存到 `Echo/DiscoveredEchoes.json` |
| `EchoSystemManager`、`EchoPopupUI` | 首次发现提示 | 右上角盖 ECHO 印章、打出文字，打完停 2 秒后淡出，重复发现不弹出 |
| `CameraPhotoStorage`、`CameraPhotoAlbumUIManager` | 保存结果 | 确认 PNG 和相册清单写入完成后才返回成功，保存失败不记录新回响 |

场景回响物品使用原有材质，不添加高光效果。手账工具栏仍使用描边标记回响照片。

界面控制脚本和两种取景框位于 `Game UI Root/EchoTargetingUIRoot`，手持框根据 `CameraScreen` 的投影定位，目标检测器位于 `Gameplay Root/Managers/EchoTargetDetector`。复用现有输入及相机模式。

门卫室 `OldPhotoFrame_StreetMarket` 已配置独立编号 `street_market_photo`、正面限制和手账文字，正文见[游戏文本](../../game-text.md)。


## 验收

在 Play Mode 中检查以下行为。

1. 手持模式的白框位于相机画面中央，全屏模式的白框位于屏幕中央。文字使用现有 UI 字体，位于各自取景画面顶部，字号和边距比例一致，并有轻轻落下回弹的入场动画。
2. 对准未发现的街道照片并满足条件时变黄，显示未发现提示；移开或离远后恢复白框并隐藏文字。
3. 全程没有模型发光、描边、材质替换或退出取景后残留的高光效果。
4. 仅出现黄框不会记录回响。黄框时按下快门并保存成功后，照片回响文字和手账显示均正常；白框拍照或保存失败时不改变发现状态。
5. 再次对准已发现物品时仍显示黄框，文字为 `Discovered Echo`；重新进入游戏后状态保持。
6. 没有回响的普通照片仍能拍摄，保存的照片不含取景框或提示文字。
7. 手持与全屏切换、收起相机、打开面板及关闭照片预览后，没有残留提示或两套框同时显示。
8. 多个回响同时符合条件时，只提示并记录最靠近中心的一个。旧照片已关联的多个回响文字不丢失。
9. 斜着拍但能看清照片正面、且满足距离和取景范围时，可以出现黄框并记录回响；只拍到相框背面不行。
10. 曾经出现黄框，移开变回白框后再拍照，不记录回响；黄框时按下快门后，即使拍摄界面隐藏，也不丢失这次判定。
11. 不同大小的回响自动使用自身模型范围判定，桌子、房间和其他无关模型不影响结果，不需要逐个手画识别区域。
12. 轻微手抖不让黄白框反复闪烁，明显移开或目标被挡住后及时恢复白框。
13. 首次发现保存成功后右上角盖下 ECHO 印章，再打出 `New Echo Discovered`，停 2 秒后淡出，重复拍摄不再弹出。
14. 手持框保持清晰并跟随相机屏幕，变黄时四角轻微外扩，失去目标后收回；默认不显示构图网格。
15. 新游戏未获得日记时，拍摄回响物品也不触发回响、计数或通知；与摩托车交互后才开启，旧照片不追溯记录。旧存档保持原有发现记录并默认日记已获得。
16. 对准山路图、纸够大但对焦距离离纸很远时，框保持白色，框下显示 `Out of focus`，按快门不记录回响；把对焦拖到纸的距离附近、画面里字变清楚时，小字消失、框变黄。光圈开大后清晰范围变窄，要对得更准。
