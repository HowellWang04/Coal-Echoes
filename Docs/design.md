# Coal Echoes 设计文档

每关开始时显示章节标题，用表中的英文。

## 键位

1. 基础WASD行走，鼠标转动视角
2. F键：交互性
3. E键：查看性
   - 查看写着中文的纸片时按 T：纸片摆正，鼠标移到哪处字上就显示英文；拍下的这张纸在相册里点开也能这样看
4. V键：相机手持与全屏模式切换，只有全屏能拍照，全屏可调整细致摄影参数
5. R键：相机模式中切换闪光灯开关，闪光会拍进照片
6. 长按 Space：第三关坐吊斗上山时跳过这段路
7. 长按 Esc：读完结尾以后回到报纸主菜单
8. A、D 或左右方向键：打开 Player's Panel 时给日记、相册和手账翻页

## 系统组成

- Grandpa's Diary （外公日记本）
- Player's Scrapbook （玩家手账）
- Player's Backpack（玩家背包）
  - 流程道具：开门、剪链等工具，在对应交互点按 F 使用
- Echo Systems（回响系统）：用相机拍下还留着外公那个年代痕迹的物品或场景，就算发现一个回响；取景时对准回响会有提示，详见[回响系统 Spec](Specs/Systems/echo-system-spec.md)
  - 回响照片和普通照片看起来不一样，放进手账时带着主人公写下的一段话，把现场看到的东西和主人公的感受连在一起
  - A 类回响：主线必须拍到，拍到后推进关卡
  - B 类回响：可选，解锁补充叙事，不影响通关

## 关卡详细流程

### 开场：时间流逝

- 主菜单报纸右页的照片是通讯员随运输班检修索道时，从山上的索道塔架往山下俯拍的厂区，画面里能看到缆绳和塔架
- 天空快速掠过，宿舍楼由新变旧
- 几十年的积沙在厂内堆成三堆沙丘，挡住主路。开场画面里看不到沙丘，玩家走进大门才发现路被埋了，不能直接走到工厂后方，要从宿舍绕行（见关卡2）
- 索道上的吊斗开场时静止不动，第三关玩家在索道下站给驱动电机上油，电机重新转起来，索道才动（见关卡3）
- 开场文字期间画面停在天空；镜头降下时玩家已经站在厂门外，第一次看到摩托车和锁着的大门
- 开场文字结束、镜头降到玩家视角时显示第一关标题，之后玩家开始操作

### 关卡1：工厂大门

**概述**

- 起点：工厂大门前摩托车旁；终点：剪断铁链、打开 Factory Gate
- 教学点：Player's Panel 四个 Tab、Camera、F 交互、E 查看
- 叙事作用：Group Photo 与 Grandpa's Diary 第一页引出故事；值班日记本暗示有工友偷偷跑到山顶看风景
- 情绪基调：失落转期待。前半段安静、疏离，照片里站满人的大门和眼前锁着的大门对不上，失落为主；值班记录本引出好奇；大门打开时主人公对外公说“我进来了”，转成期待

**关键流程**

1. 摩托车储物箱 → 拿到 Grandpa's Diary、Group Photo、Lock Pick
2. → 在大门前光圈内重拍 Group Photo
3. → 用 Lock Pick 撬开门卫室 → 拿到 Bolt Cutter
4. → 剪断铁链 → 打开 Factory Gate，第一关完成

### 关卡2：宿舍楼

**概述**

- 起点：穿过 Factory Gate 进入厂区；终点：读完离开宿舍的过场文字，已经从宿舍后门绕过沙丘，来到工厂后方
- 教学点：照着 Grandpa's Diary 找线索。提示只说要找什么，东西在哪要从日记里读出来；第一次调相机参数，拍山路图要拉长焦距、对好焦，纸上的字拍清楚才算拍到
- 叙事作用：207 室和 Grandpa's Diary 对上，玩家走进外公和工友生活过的房间；日记第二页和山路图把两人上山看灯的约定第一次摆在玩家面前，说好上山那晚才拿出来的图还收在抽屉里
- 情绪基调：亲近转决心。前半段路被沙丘埋住，只能从宿舍穿过去；进了 207 室，床、桌子和炉子都和日记写的一样，像走进外公当年的日子，亲近为主；山路图还收在抽屉里，主人公没有拿走它，只拍下来，决定替外公和工友上那道山脊看看，转成决心

**关键流程**

1. 进入厂区，看到主路被沙丘埋住
2. → 用 Lock Pick 撬开宿舍入口 → 过场文字后传送到 207 室
3. → 照着 Grandpa's Diary 在桌子半开的抽屉里找到山路图 → 查看并拍下山路图
4. → 离开 207 室，过场文字里绕过沙丘来到工厂后方，第二关完成

### 关卡3：索道站始发站

**概述**

- 起点：读完离开宿舍的过场文字后，接着第三关开头的过场文字，主人公照着拍下的山路图沿主路走到尽头；终点：坐吊斗在夜里到山顶站，站到上站站台上
- 教学点、叙事作用、情绪基调 **待定**

**关键流程**

1. 过场文字里跟着山路图沿主路走到尽头，显示第三关标题
2. → 从主路尽头沿小路走到索道下站
3. → 在驱动电机旁拿到 Oil Can → 给电机上油，电机启动，索道动起来
4. → 站里那只吊斗开到上山的站台边，按 F 爬进去
5. → 坐吊斗上山，路程长，可以长按 Space 跳过
6. → 快到站时黑屏读过场文字，天在路上黑了下来
7. → 吊斗在夜里开到山顶站门口停下，视线转向站台，站到站台上，第三关完成

### 关卡4：索道终点站

**概述**

- 起点：第三关吊斗在山顶站门口停下后，站到上站站台上，已是月夜；终点：在山头先拉近拍下山脚外公住过的宿舍楼，再把厂区和星空拍进同一张照片，放进手账，读完结尾文字，游戏结束
- 教学点：不教新操作，用前面学过的日记、相机和手账收尾
- 叙事作用：走到外公和工友约好的山脊，在这里读日记最后一页，确认他们直到停产都没上来过；外公和工友当年从 207 的窗口望山上，主人公从山头拉近望回那扇窗；主人公替他们看了这一眼，把看到的拍下来，和开头的旧合照收进同一本手账，首尾呼应
- 情绪基调：遗憾转释然。走上山头，山下的厂区一片漆黑，没有他们想看的灯火，读完最后一页，拉近看到宿舍楼的窗户全黑着，遗憾为主；放宽镜头，抬头是月光和星空，只听得见风，把这一幕拍下来放进手账，转成释然和静谧

**关键流程**

1. 到站后站在上站站台上，显示第四关标题
2. → 从站房背后的木栈道走上山头，就是山路图上画叉的山脊
3. → 在山头读 Grandpa's Diary 最后一页
4. → 站在观景平台上拉近、对焦，拍下山脚厂区里外公住过的宿舍楼
5. → 把焦距拉回来，把山下的厂区和星空拍进同一张照片
6. → 把这张照片放进手账 → 读完结尾文字，游戏结束

## 外公日记关键内容

日记从 1980 年 10 月外公调到洗煤厂写起，写到 1988 年前后洗煤厂停产为止。共四页，每页两篇，大致一关一页，正文见[外公日记](json-grandpa-diary.md)。

- 前密后疏：前五篇都在进厂头三个月，之后一篇隔两三年。篇与篇之间的空档越拉越长，玩家不看文字也能感到“说了下回，一晃又是好几年”
- 拿到日记就能翻到全部页面，所以日记只写外公当年的日常，约定是顺口提起、一再推迟，不直接写“没去成”；一直没去成留到第四关站在山脊上读最后一页时确认
