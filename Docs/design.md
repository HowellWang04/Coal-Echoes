# Coal Echoes 设计文档

## 关卡地图

关卡分为四关：

工厂大门 | 宿舍楼 | 索道站始发站 |  索道终点站

游戏内英文：

The Factory Gate | The Dormitory | The Lower Station | The Upper Station

每关开始时屏幕中央显示章节标题，上一行小字 Chapter One 到 Chapter Four，下一行大字关名。

## 键位

1. 基础WASD行走，鼠标转动视角
2. F键：交互性
3. E键：查看性
4. V键：相机手持与全屏模式切换，全屏可调整细致摄影参数
5. R键：相机模式中切换闪光灯开关，闪光会拍进照片

## 系统组成

- Grandpa's Diary （外公日记本）
- Player's Scrapbook （玩家手账）
- Player's Backpack（玩家背包）
  - 流程道具：开门、剪链等工具，在对应交互点按 F 使用
- Echo Systems（回响系统）：用相机拍下还留着外公那个年代痕迹的物品或场景，就算发现一个回响；取景时对准回响会有提示，详见[回响系统 Spec](Specs/Systems/echo-system-spec.md)
  - 回响照片和普通照片看起来不一样，放进手账时带着主人公写下的一段话，把现场看到的东西和主人公的感受连在一起
  - 每发现一个回响，计入本关的回响收集进度
  - A 类回响：主线必须拍到，拍到后推进关卡
  - B 类回响：可选，解锁补充叙事，不影响通关

## 关卡详细流程

### 开场：时间流逝中的沙丘

- 主菜单报纸右页的照片是通讯员随运输班检修索道时，从山上的索道塔架往山下俯拍的厂区，画面里能看到缆绳和塔架
- 照片放大和纸墨消退期间，厂内的三堆沙丘从地下升起，表现多年积沙
- 沙丘留在场景里，挡住主路，玩家进厂后不能沿主路直接走到工厂后方，要从宿舍绕行（见关卡2）
- 天空快速掠过，宿舍楼由新变旧
- 开场文字期间镜头对着天空，从塔架机位换到厂门外；镜头降下时玩家才第一次看到摩托车和锁着的大门
- 开场文字结束、镜头降到玩家视角时，画面上下的黑边收回，同时渐显第一关标题 Chapter One / The Factory Gate，停一会儿再渐隐，之后玩家开始操作

### 关卡1

**概述**

- 起点：工厂大门前摩托车旁；终点：剪断铁链、打开 Factory Gate
- 教学点：Player's Panel 四个 Tab、Camera、F 交互、E 查看
- 叙事作用：Group Photo 与 Grandpa's Diary 第一页引出故事；值班日记本暗示有工友偷偷跑到山顶看风景
- 情绪基调：待定

**关键流程**

1. 摩托车储物箱 → 拿到 Grandpa's Diary、Group Photo、Lock Pick
2. → 在大门前光圈内重拍 Group Photo
3. → 用 Lock Pick 撬开门卫室 → 拿到 Bolt Cutter
4. → 剪断铁链 → 打开 Factory Gate，第一关完成

### 关卡2

**概述**

- 起点：剪断铁链、进入厂区；终点：从宿舍另一侧出口离开，绕过沙丘到达工厂后方
- 背景：洗煤厂是突然关闭的，外公那一批工人是最后住在宿舍的人，之后没有新人入住，外公住过的房间保留着当年的样子
- 关卡结构：厂内主路被开场隆起的沙丘挡住，宿舍是绕过沙丘的唯一通路
- 叙事作用、教学点、情绪基调：待定

**流程**

| 步骤 | 玩家行为                                                 | 完成条件               | 提示文本 | 解锁内容              |
| ---- | -------------------------------------------------------- | ---------------------- | -------- | --------------------- |
| 1    | 进入厂区，沿主路走，发现主路被沙丘挡住                   | 待定                   |          |                       |
| 2    | 来到宿舍入口，用 Lock Pick 打开上锁的入口                | 打开宿舍入口           |          | 播放过场文字          |
| 3    | 阅读过场文字，跟随外公日记第一页写的房间号来到外公的寝室 | 读完最后一段并点击继续 |          | 传送到外公寝室 207 室 |
| 4    | 在外公的寝室里寻找某样东西（待定）                       | 待定                   |          | 待定                  |
| 5    | 从宿舍另一侧出口离开，绕过沙丘                           | 到达工厂后方           |          | 第二关结束            |

**过场文字**

- 撬开宿舍入口后画面淡出，居中显示过场文字，读完后淡入，玩家已站在外公寝室内
- 文字的阅读方式与开场文字相同，不能跳过
- 背景用黑屏还是其他画面待定，以下文字为草稿
1. In his diary, Grandpa wrote down the room he was given when he first arrived. Room 207, on the second floor.
2. I followed his words up the dark stairwell. The doors along the corridor all looked the same, but I knew which one was his.
3. No one moved in after them. The room had been waiting, just as he left it.
