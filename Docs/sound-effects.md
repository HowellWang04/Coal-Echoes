# 音效列表

只列音效和环境声，不含音乐。全游戏都会用到的玩家、相机和界面声音放在最前面的通用一节，其余按关卡出现的先后排。

## 通用

### 玩家

| 音效 | 用途 |
| --- | --- |
| 沙土地脚步 | 厂门外、厂区主路、工厂后方的土路和去山脚站的路上走动时，脚下是干土和积沙，踩着发沙 |
| 软沙堆脚步 | 踩上宿舍楼前院的积沙堆和沙丘时，比土路更软更闷，脚陷进沙里 |
| 水泥地脚步 | 门卫室、207 室，厂门的水泥门槛、宿舍楼门前和厂区的水泥地坪，以及山顶站站房基础顶面，比室外硬、短，屋里听得出一点回声 |
| 木栈道脚步 | 第四关站房背后的木栈道、台阶和观景平台，旧木板被踩得发空的闷响 |

### 相机

| 音效 | 用途 |
| --- | --- |
| 举起、放下相机 | 按 1 把相机举到手上或收起，背带和机身摩擦的短声 |
| 切换手持与全屏 | 按 V 时相机贴到眼前或拿开，很轻的机身声 |
| 快门 | 全屏取景时按下快门拍照，干脆的机械快门声；手持时快门没有反应，不出声 |
| 闪光灯开关 | 相机模式中按 R 开关闪光灯，小开关的咔嗒 |
| 闪光 | 开着闪光灯拍照时和快门一起响，短促的闪光放电声 |
| 相机调参 | 全屏取景里拖动焦距、光圈、对焦距离、暗角、曝光、泛光、饱和度滑条时细小的刻度声；切换参数页签、开关网格、重置时的按键声 |
| 回响取景框变黄 | 取景时对准回响、四角框从白变黄的那一刻，一声很轻的提示，玩家不盯着框也知道对上了 |
| 拍到回响 | 黄框时拍下照片，快门之后多一层很轻的回音，和普通照片区分开；Group Photo 重拍、山路图这些 A 类回响也是这一声 |

### Player's Panel

| 音效 | 用途 |
| --- | --- |
| 打开、关闭面板 | 按 Tab 时 Player's Panel 滑入滑出，像翻开、合上一本旧本子 |
| 切换页签 | 点 Grandpa's Diary、Scrapbook、Backpack、Photo Album 四个页签时的翻纸声 |
| 点没开放的页签 | 第一关教学期间点了还没开放的页签，图标左右抖一下，配一声发闷的短音，告诉玩家现在点不开 |
| 日记翻页 | Grandpa's Diary 翻页动画时的旧纸翻页声 |
| 相册翻页 | Photo Album 点 Previous Page、Next Page 或按 A、D 翻页时，比日记翻页轻 |
| 照片加进手账 | 相册照片右键 Add to Scrapbook，照片飞进手账时的纸片声 |
| 手账摆放 | Scrapbook 里拿起照片或贴纸、放下贴好时的纸片声；拖到页面外放不下时换成发闷的短音 |
| 手账删除 | Scrapbook 里右键 Delete，元素溶解消失时的轻声 |
| 手账写字 | 在 Scrapbook 的文本框里打字时很轻的笔尖声 |

### 提示与查看

| 音效 | 用途 |
| --- | --- |
| 新任务提示 | 右上角出现新的任务提示时轻的一声 |
| 任务勾选 | 任务框被铅笔从左上往右下涂满时，铅笔涂抹的沙沙声 |
| 拾取物品 | 按 F 拿到物品、右下角出拾取提示时；摩托车一次拿到三样，三行依次滑入，声音也依次响，不叠成一团 |
| 首次发现回响 | 右上角 ECHO 印章盖下的一刻，比任务提示更有分量的一声，像橡皮章按在纸上 |
| 查看物品 | 按 E 查看或在 Backpack 里点开物品时，物品飞到眼前、放回原处的轻声；值班记录本、山路图有自己的拿放声，列在对应关卡 |
| 章节标题 | 每关开始写出 Chapter One 到 Chapter Four 的标题时，一声低而长的音 |
| 过场文字换段 | 开场、进出宿舍、第三关到站的黑屏文字点击换段时的轻声 |

## 主菜单与开场

| 音效 | 用途 |
| --- | --- |
| 主菜单底音 | 报纸主菜单期间很远、很轻的洗煤厂运转声，机器、索道和人声混在一起，是厂子还活着时的声音 |
| 菜单按钮 | 悬停和点击 Start New Game、Continue；没有存档时 Continue 置灰，点了只出发闷的短音 |
| 报纸转场 | 点击开始后照片放大、纸墨褪去时的纸张声，年份从 1980 翻到 2026 时数字翻动的声音 |
| 时间流逝 | 云飞快掠过、宿舍楼由新变旧时，主菜单的运转声越退越远直到没有，只剩风越吹越大，几秒里过去几十年 |
| 开场天空风声 | 开场文字期间镜头对着天空，高处空旷的风；镜头降到厂门外时接上第一关的环境声 |

## 第一关　工厂大门

| 音效 | 用途 |
| --- | --- |
| 厂门外环境声 | 厂门外和门卫室外，戈壁上的风和吹起的细沙，偶尔有铁皮被风吹响；安静、疏离，没有人声 |
| 铁链碰门 | 锁着的大门上铁链被风吹得轻碰铁门，剪断铁链后就没有了 |
| 门卫室室内环境声 | 进了门卫室，外面的风变闷，屋里更静 |
| 摩托车储物箱 | 第 3 步按 F 打开 Motorcycle 的储物箱，拿出 Grandpa's Diary、Group Photo、Lock Pick |
| 撬锁 | Lock Pick 拨动锁芯、锁舌弹开，第 9 步撬开门卫室；第二关撬宿舍入口也用这一声 |
| 门卫室门打开 | 第 9 步撬开后门向外开，旧门铰链的吱呀 |
| 值班记录本 | 第 11 步按 E 拿起皮面本子到眼前、按右键放回桌上，皮面和纸页的声音 |
| 拿起 Bolt Cutter | 第 12 步按 F 拾取断线钳，沉的金属工具声 |
| 剪断铁链 | 第 12 步断线钳咬断铁链的一声脆响，接着铁链和挂锁掉在地上 |
| 大门打开 | 第 12 步两扇铁门向厂内转开，锈住的铰链长而沉的吱呀，本关从失落转成期待的那一刻 |

## 第二关　宿舍楼

| 音效 | 用途 |
| --- | --- |
| 厂区内环境声 | 进大门以后的厂区，风刮过沙丘的沙沙声比门外更近，厂房铁皮偶尔被吹响 |
| 宿舍入口门 | 第 2 步撬开宿舍入口后推开正门，接着进入过场黑屏 |
| 进入宿舍过场 | 第 3 步黑屏过场文字期间，上楼的脚步、楼道里的回声和推开 207 室门的声音 |
| 207 室环境声 | 第 4 步起，屋里很静，窗外的风被玻璃挡住变闷，旧窗框偶尔被吹得轻响 |
| 桌子抽屉 | 第 6 步拉开桌子半开的木抽屉、看完后推回去 |
| 山路图 | 第 6 步按 E 拿起旧工票、翻到背面看路线、放回抽屉时的薄纸声 |
| 207 室门 | 第 8 步在门口按 F 离开房间，开门后进入过场黑屏 |
| 离开宿舍过场 | 第 9 步黑屏过场文字期间，下楼的脚步、拉开后门的门闩、推开后门，最后是楼后空场上的风 |

## 第三关　索道站始发站

前段流程 **待定**，目前只列让索道动起来和结尾坐吊斗上山这一段。

| 音效 | 用途 |
| --- | --- |
| 静止的吊斗 | 索道动起来之前，吊斗挂在缆绳上被风吹得轻晃，吊架和缆绳吱嘎作响 |
| 索道启动 | 索道从静止动起来，驱动轮转起来、缆绳绷紧，几十年没动过的铁件一起响 |
| 爬进吊斗 | 踩进铁皮斗底的金属闷响 |
| 吊斗运行 | 坐吊斗上山一路，抓绳器在缆绳上滑行的持续声，加上吊斗轻晃的吱嘎和高处的风 |
| 经过塔架 | 吊斗经过每座塔架时压过滚轮的咔嗒声，玩家像山路图上写的那样数着塔架上山 |
| 长按跳过 | 长按 Space 时随跳过提示的下划线填满渐渐升起的一声，松手取消时跟着断掉 |
| 到站前黑屏 | 快到站时的黑屏过场期间吊斗的声音淡下去，白天的风慢慢换成夜里的风；淡入时已是月夜，吊斗运行声接着响到停下 |
| 索道停下 | 吊斗开到山顶站门口时整条索道停住，驱动轮慢下来、缆绳松下来，吊斗晃一下停稳的金属吱嘎声 |
